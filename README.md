# Plotline — UK Smart-City Investment Platform

Interactive hackathon demo: where should **$100,000** flow across the UK smart-city value chain, and why?

Plotline allocates a portfolio across 7 smart-city layers plus a private architecture venture, checks every split against client mandate rules, and stress-tests it under macro scenarios.

## Live demo

**https://joseyosei.github.io/plotline/** (GitHub Pages)

## Features

- **Portfolio Builder:** $100k allocation across 7 value-chain layers
- **Mandate Engine:** live pass/fail checks (per-holding cap, layer coverage, cash ceiling)
- **Stress Testing:** Base Case, Rates Shock (+200bps), Infra Cut (-15%)
- **Private Venture Score:** Go / Partial / No-go for the illiquid architecture raise
- **Transparent Thesis:** data provenance, downside risk and exit trigger for every holding

## Run locally

It's a single static file. Open `index.html` in a browser (needs an internet connection for Tailwind, Chart.js, Lucide and Google Fonts).
